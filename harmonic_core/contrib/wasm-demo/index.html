harmonic_core — the same engine, in your browser

This is wasm32-unknown-unknown, no_std, zero-dependency — the byte-for-byte identical DSP that ships in the VST3/CLAP plugin and cross-compiles to a Cortex-M board. 8 Voices through the C ABI; note allocation, stealing and the amp gate are a few lines of JS in the AudioWorklet — the host's job, same as in firmware.

Play with the mouse or the keyboard row A S D F G H J K (C major, one octave).
