How it works

The identity is older than recording. The engineering around it is the product.

A tone made of the first n cosine harmonics with a geometric rolloff has an exact closed form — a truncated complex geometric series, Lagrange's finite trigonometric sum (~1830s), in the family of Moorer's discrete summation formulae (1976):

Σk=1..n rᵏ·cos(2πkp)  =  ( r·c₁ − r² − rn+1·cn+1 + rn+2·cn ) / ( 1 − 2r·c₁ + r² )   ck = cos(2πkp)

The correction terms subtract the infinite tail exactly, so the spectrum is precisely zero above harmonic n — no anti-aliased tables, no oversampling filter on the clean path. n is clamped to Nyquist by construction, so the oscillator cannot alias. A second closed-form term — the difference of two such sums — adds one movable resonant hump (Formant). Saw and triangle are separate, band-limited PolyBLEP / PolyBLAMP, flat all the way to DC.

The one expensive quantity, rⁿ, is a single exponentiation-by-squaring (≤ 22 multiplies for n ≤ 2048) and is cached on a held note — which is why the cost is flat in practice. Full derivation and every measured number: the scientific monograph.

For developers

The same engine, without the plugin.

Underneath the Cosine plugin (harmonic_synth) is harmonic_core — a no_std, zero-dependency Rust DSP crate with a C ABI. The plugin is one host for it.

  • Zero dependencies, no libm, no allocator. ~14 KB no_std cdylib. Links into firmware as-is.
  • One Voice is plain-old-data (624 bytes, no pointers) — the caller owns the memory, the crate never allocates and never panics on the audio path. Polyphony is the host's policy.
  • Cross-compiles clean to Cortex-M4F/M7 (Daisy Seed), Cortex-M0 (soft-float), RISC-V, AArch64 — and wasm32, where an 8-voice browser demo runs the identical code with note allocation in ~40 lines of JavaScript.
  • Regression-test audio by hash. The determinism contract means a render is reproducible across machines; a shared verify module renders two scripted passes and every target checks them against the same 64-bit values in CI.
  • Verified: 120 core tests (11 an adversarial RT-safety suite — NaN / ±∞ / parameter storms), 34 plugin + 9 licence tests, pluginval --strictness 8, clap-validator 35/35, ARM + wasm bit-exactness under QEMU / Node, all on every push.

What it won't do

Published, not buried. In this market that's the marketing.

  • Not a general O(1) additive synth. The closed form works for a spectral tilt plus one hump. An arbitrary per-harmonic envelope is Θ(n) again.
  • The oscillator is alias-free; the effects are not. Drive, Fold, Grit, FM, feedback and the soft-clip generate content above Nyquist by design. HQ Mode cleans it for a fixed 16 samples of latency.
  • HQ Mode does not reduce CPU. It's an anti-aliasing quality mode, roughly CPU-neutral. Stated plainly everywhere.
  • Microtuning retunes the fundamental, not the partials. Just / historical / EDO / Scala scales work; bell inharmonicity and stretched-piano tuning need a different kernel.
  • Monotimbral, one MIDI channel. 2048-harmonic ceiling. Voice-steal click past the polyphony limit.
  • Real embedded hardware isn't measured yet — cross-compiles clean and is bit-exact under QEMU / in Node, but not on a physical Cortex-M board. macOS / Linux builds and an AU format are pre-launch work.

FAQ

The questions a skeptic asks first.

Is it really O(1)?

No — and we won't say it is. It's Θ(log n) worst case (one rⁿ by squaring, ≤ 22 multiplies), and Θ(1) amortised because that term is cached on a held note. Measured: flat within 1 % from 3 to 1200 harmonics. A brightness sweep or a pitch change pays the log n again.

Does it alias?

The oscillator does not — the harmonic count is clamped to Nyquist by construction and the closed form is the exact finite sum, so nothing lives above partial n. The nonlinear stages (Drive, Fold, Grit, FM, feedback) do alias when pushed — that's intentional character. The built-in aliasing meter tells you when, and HQ Mode is the clean path.

Why doesn't HQ Mode save CPU?

Because there was never a per-partial decimator to remove — the oscillator is already band-limited. HQ oversamples the whole chain to stop the effects aliasing; that costs about as much as it saves from merging the decimators. It's a quality mode, not a performance mode, and it adds exactly 16 samples of latency. We say this everywhere.

What's "bit-identical" worth to me?

A freeze sounds exactly like real-time. A bounce on your laptop matches the one on the studio Mac. A render today matches one from last month. And if you ship the engine in hardware or a game, the same input produces the same audio on every client — you can regression-test it by hashing the output.

VST3 and CLAP — where's AU / AAX?

VST3 + CLAP at launch. AU (for Logic) needs a wrapper and is planned. AAX (Pro Tools) is not currently on the roadmap — it would require a hardware dongle, which contradicts the no-dongle promise.

Where does the name come from?

Every note is literally a finite sum of cosine partials in closed form — Σ rᵏ·cos(2πkp). The name states the method and claims nothing. The domain is still being registered before the first public release; the engine and the plugin are real and validated today.
