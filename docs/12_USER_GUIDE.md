# 12 — Практичний гайд: збірка, встановлення, використання

`harmonic_synth` — поліфонічний MIDI-інструмент (**VST3 + CLAP**) на
`harmonic_core`. Кожна нота — band-limited адитивний тон із закритої форми
ядра Діріхле: без вейвтейблів, без циклу по гармоніках, без оверсемплінгу
(окрім опційного HQ-режиму).

> Це **dev-facing** гайд: збірка з коду, інтеграція в DAW, повний довідник
> параметрів, траблшутинг. Стислий **англійський посібник кінцевого
> користувача** (той, що постачається з завантаженням плагіна) —
> [`../harmonic_synth/MANUAL.md`](../harmonic_synth/MANUAL.md). Комерційні
> матеріали — [`../product/`](../product/README.md).

---

## 1. Збірка з коду

Потрібен Rust `stable` (проєкт закріплено на `1.97`; nih-plug тягне важке
дерево — перша збірка кілька хвилин).

```
cd harmonic_synth

# швидка перевірка, що плагін компілюється
cargo build --release

# повні бандли VST3 + CLAP
cargo xtask bundle harmonic_synth --release
```

Результат:

```
target/bundled/harmonic_synth.vst3     (тека-бандл: Contents/x86_64-win/…)
target/bundled/harmonic_synth.clap     (один файл)
```

Опційно — прогнати валідатори (потрібні `pluginval` і `clap-validator` на
`PATH` або в `harmonic_synth/tools/`; pwsh-скрипт має `-Fetch` для
автозавантаження):

```
cargo xtask validate
```

## 2. Встановлення в DAW

### Варіант А — системні теки плагінів

Скопіювати в стандартні теки (потребує прав на запис — на Windows це
зазвичай адміністратор):

| ОС | VST3 | CLAP |
|---|---|---|
| Windows | `C:\Program Files\Common Files\VST3\` | `C:\Program Files\Common Files\CLAP\` |
| Linux | `~/.vst3/` | `~/.clap/` |
| macOS | `~/Library/Audio/Plug-Ins/VST3/` | `~/Library/Audio/Plug-Ins/CLAP/` |

VST3 копіюється як **тека** `harmonic_synth.vst3` цілком, CLAP — як файл.

### Варіант Б — додаткова тека сканування (без адмін-прав)

Більшість DAW дозволяють вказати власну теку для сканування плагінів —
можна навести її прямо на `target/bundled/` і нічого не копіювати.

**REAPER:**
1. `Options → Preferences` (`Ctrl+P`).
2. `Plug-ins → VST` → поле «VST plug-in path(s)» → **Add** →
   `…\harmonic_synth\target\bundled` → **Re-scan**.
3. `Plug-ins → CLAP` (окрема сторінка у сучасних версіях) → той самий шлях →
   Re-scan. У деяких версіях CLAP сканується з VST-шляхів автоматично.

Ключі в `reaper.ini` (секція `[reaper]`), якщо редагувати напряму при
закритому REAPER: `vstpath64=…` і `clap_path_win64=…` (шляхи через `;`).

## 3. Швидкий старт

1. Створити нову доріжку (`Track → Insert New Track`).
2. Відкрити FX доріжки → пошук **«Harmonic»** → додати `Harmonic Synth`
   (VST3 або CLAP — звучать ідентично).
3. **Увімкнути моніторинг доріжки**, інакше наживо звуку не буде:
   - **REAPER:** натиснути **Record-arm** (кнопка `R` на доріжці) — тоді
     віртуальна клавіатура (`View → Virtual MIDI Keyboard`) і зовнішня
     MIDI-клавіатура долітають до синтезатора.
   - Інші DAW: увімкнути «Input Monitoring» / «Monitor» на доріжці.
4. Грати нотами (MIDI-клавіатура, віртуальна клавіатура, або намалювати
   MIDI-айтем).

Плагін стартує в **чистому** стані: `Drive/Fold/Grit/FM/Feedback = 0`,
`Filter = Off`, `Brightness = 35 %`. Це майже синус із геометрично-спадними
гармоніками.

### Пресети

Угорі редактора — рядок **`◀ ім'я ▶`**. Стрілки гортають стартовий банк
(22 пресети: баси, ліди, пади, клавішні, дзвони, текстури). Це відправна
точка — після завантаження крути ручки далі; ім'я лишиться показувати
останній завантажений пресет. Пресети зберігаються з проєктом (стан
параметрів), окремого браузера з категоріями поки немає.

## 4. Параметри

| Параметр | Діапазон | Що робить |
|---|---|---|
| **Oscillator** | Geometric / Saw / Triangle | Geometric — закрита адитивна форма (реагує на Brightness + HQ). Saw/Triangle — PolyBLEP/PolyBLAMP (ігнорують Brightness і HQ). |
| **Brightness** | 0–100 % | Геометричний нахил спектра `r`. 0 % ≈ чистий синус, 100 % ≈ яскравий імпульс. |
| **Partials** | 1–2048 | Стеля на кількість гармонік — плавний свіп від чистого синуса (1) до повного band-limited імпульсу (2048); дробові значення підмішують наступну гармоніку, тож перехід гладкий навіть на 1→2→3. На відміну від Brightness (нахил) — це **обрізання** спектра. **CPU не змінюється** на жодному значенні, **ніколи не аліасить** (стеля ≤ Найквіста). Тільки Geometric. |
| **Expr → Bright** | −100 – +100 % | Понотна яскравість: MPE-тембр (вісь Y / CC74), поліфонічний афтертач і тиск каналу керують `rolloff` **кожної ноти окремо**. Натиснув сильніше на одну клавішу акорду — більше обертонів саме в ній. Дефолт `+35 %`; `0` вимикає; від'ємні значення інвертують (сильніше → темніше). Тільки Geometric. |
| **Formant** | 0–100 % | Резонансний горб у середніх обертонах — «голосний» / формантний характер. Нижчі значення ставлять горб на нижчий обертон, вищі — на вищий (≈ 2-й … 26-й), і роблять його глибшим. `0 %` вимикає (без ефекту). Другий закритий член — CPU майже не зростає. Тільки Geometric. |
| **Attack / Release** | 0.5 мс – 2 с · 5 мс – 5 с | Амплітудна обгинаюча (attack лінійний, release експоненційний). Sustain фіксовано на 1 (AR-обгинаюча). |
| **Gain** | −60 – 0 дБ | Майстер, перед soft-clip. |
| **Drive** | 0–100 % | Асиметричне насичення (bias їде разом). «Жир». |
| **Fold** | 0–100 % | Рефлективний вейвфолдер. Щільний рухливий верхній спектр. |
| **Grit** | 0–100 % | Bit-crush + пониження SR разом. Ранньоцифровий бруд. |
| **FM Amount / FM Ratio** | 0–4 · 0.5–12 | Фазова модуляція синусним оператором. Цілі Ratio — гармонічно, дробові — кланг. |
| **Feedback** | 0–0.9 | Самофідбек оператора. Синус → пила → шум. |
| **Filter** | Off / LP / BP / HP / Notch | ZDF SVF після Character-стадії. |
| **Cutoff / Resonance** | 20 Гц – 20 кГц · 0–100 % | Q `0.5 → 32`, без самозбудження. Cutoff автоматизується по-блоково. |
| **Filter Env** | −6 – +6 окт | Окрема фільтрова обгинаюча → cutoff, посемплово на голос. Біполярна. |
| **F.Env Attack/Decay/Sustain/Release** | | Власна ADSR фільтрової обгинаючої, незалежна від амплітудної. |
| **Free-Run Phase** | on / off | Аналоговий стиль: фаза осцилятора не скидається на note-on. |
| **HQ Mode** | on / off | `2×` оверсемпл усього тракту, щоб Drive/Fold/Grit/FM не аліасили. **+16 семплів латентності** (повідомляється хосту, PDC компенсує). CPU при цьому суттєво не зростає, але й не падає. |
| **Unison** | 1–8 | Стек розстроєних + стерео-рознесених голосів на ноту (гейн `1/√n`). |
| **Uni Detune / Uni Spread / Uni Drift** | 0–50 ц · 0–100 % · 0–100 % | Розстройка, стерео-ширина, і повільний незалежний дрейф фази на голос («дихання» образу). |
| **Tuning** | Equal / Just / Pythagorean / ¼-comma Meantone / 19-EDO / 24-EDO / 31-EDO / Bohlen-Pierce | Нота→частота. `Equal` = 12-TET (дефолт). Решта ретюнять **фундаментал** кожної ноти; обертони лишаються на `k·f0` (див. нижче). Діє з наступної ноти. |
| **Tune Root** | C … B | Тоніка 12-нотних історичних шкал (Just / Pythagorean / Meantone). Ігнорується для `Equal` та EDO. |
| **Tune Ref** | 415–467 Гц | Опорна частота A4. `440` — стандарт; `432` тощо масштабують увесь стрій. |
| **Scala** (поле) | шлях до `.scl` або вставлений вміст | Будь-яка Scala-шкала — відношення (`3/2`) або центи (`701.955`), до 64 нот. Перекриває список Tuning. `✕` очищає. Шкала зберігається з проєктом. `.kbm` та MTS-ESP поки не підтримуються — клавіатура мапиться лінійно від **Tune Root**. |
| **Bend Range** | 1–24 пт | Діапазон колеса висоти. |
| **LFO Rate / Shape / Sync** | 0.02–30 Гц · sine/tri/saw · Retrigger/FreeRun | По-голосний LFO. Retrigger — фаза скидається на note-on; FreeRun — біжить крізь ноти. |
| **LFO → Bright / Vibrato / Cutoff / FM** | ±100 % · 0–100 ц · ±4 окт · ±4 | Матриця модуляції LFO. Кожна ціль `0` не застосовується; усі нулі → LFO не рахується взагалі. |

Drive / Fold / Grit / FM / Feedback навмисно виводять контент за Найквіст і
аліасять на сильних значеннях (характер PPG / DX7). Для чистого результату —
**HQ Mode**. На нулі все одно чисто.

### Мікротюнінг

`Tuning` кладе зіграну ноту на потрібну частоту — чиста інтонація, Пифагор,
мезотоніка, рівні поділи (19/24/31 на октаву), Bohlen-Pierce, інша опорна
частота. Для 12-нотних історичних шкал `Tune Root` вибирає тоніку.

Що це **робить**: additive-осцилятор будує обертони строго на `k·f0`, тож коли
`f0` у чистій інтонації — увесь тон точно в строю сам із собою, і акорд
перестає «битися». Що це **не робить**: не зсуває окремий обертон з
гармонічної сітки (дзвін / розтягнутий рояль цим ядром не зробити — `07 §20`).
`Equal` при `Tune Ref = 440` — це рівно 12-TET, побайтово дефолт.

### Метр аліасингу

Праворуч від спектр-дисплея — вузька кольорова смуга: рівень енергії біля
Найквіста. Осцилятор сам по собі туди нічого не кладе, тож коли смуга
підіймається — це нелінійні стадії аліасять. **Зелена** — чисто; **бурштин**
— межа; **червона** — увімкни **HQ Mode** (смуга одразу впаде). Це найпростіший
спосіб не гадати, коли HQ реально потрібен, а коли ні. Працює лише поки
відкрито редактор.

### A/B морф

Рядок `SET A · слайдер · SET B` під метром аліасингу.

1. Налаштуй звук — тисни **SET A** (знімок усіх параметрів у слот A).
2. Змінюй параметри як хочеш — тисни **SET B**.
3. Тягни слайдер: `pos = 0` — рівно A, `pos = 1` — рівно B, між ними — плавна
   суміш **кожного** параметра.

Слайдер пише інтерпольовані значення у справжні ручки — тож звук точно
відповідає тому, що показує GUI, і хост записує рух як звичайну автоматизацію.
Слоти A/B і позиція зберігаються з проєктом.

**Межі.** Дискретні перемикачі (Oscillator, Filter, LFO Shape/Sync, HQ Mode,
Free-Run) стрибають на середині слайдера, а не плавляться — для суто
тембрового морфу тримай їх однаковими в A і B. Морф діє лише поки редактор
відкритий; окремого «параметра морфу» для автоматизації однією доріжкою немає.

### Random / код

Рядок `RANDOM · поле коду` під морфом.

- **RANDOM** — котить новий патч. Тисни, поки не сподобається.
- Поле показує **6-символьний код** цього патча. Скопіюй його, надішли в чат —
  хто завгодно введе код і отримає **точно той самий звук**, на будь-якій ОС і
  DAW (мапінг детермінований, як і решта DSP).
- Ввід коду + Enter — застосовує патч.

Рандом чіпає лише параметри звуку (не HQ Mode / Bend Range / Free-Run) і
свідомо тримається музичних діапазонів, тож придатний патч трапляється часто.
Код «пливе» від звуку, щойно крутнеш будь-яку ручку — тоді або тисни RANDOM
знову, або збережи патч через A/B-слот чи стан проєкту.

> **Код прив'язаний до версії плагіна.** Оновлення, що змінить діапазони
> рандому, зробить старі коди іншими на звук. Для архіву патча користуйся
> станом проєкту, не кодом.

## 5. MIDI

| Подія | Обробка |
|---|---|
| Note On / Off | Виділення голосу, unison-стек. 24 голоси (unison ділить пул). |
| Choke | Миттєве глушіння (ігнорує сустейн). |
| Pitch Bend | На всі звучні голоси, згладжено. Діапазон — `Bend Range`. |
| CC#64 (sustain pedal) | Поки педаль тиснута (`value ≥ 0.5`), `NoteOff` відкладається; на відпусканні всі утримані ноти звільняються. |
| CC#123 (all notes off) | Звільняє всі голоси, скидає стан педалі. |
| Poly Aftertouch / MPE-тембр (CC74) | Понотна яскравість: `rolloff` цієї клавіші. Глибина — `Expr → Bright`. |
| Channel Pressure (моно-афтертач) | Яскравість, спільна на всі звучні ноти. Глибина — `Expr → Bright`. |

Канал MIDI-подій не розрізняється — плагін монотембральний, **але понотна
яскравість адресується по клавіші**, тож MPE-експресія працює (`07 §15`).
Колесо висоти, педаль і CC#123 потребують, щоб DAW передавав плагіну сирі
MIDI CC (плагін заявляє `MidiConfig::MidiCCs`).

## 6. Траблшутинг

| Симптом | Причина / рішення |
|---|---|
| **Плагін не з'являється в списку FX** | Тека `target/bundled` не в шляхах сканування DAW, або сканування не перезапущене. Перевірити точний шлях (без нічого після `bundled`), натиснути Re-scan. |
| **Плагін завантажується, але немає звуку** | Найчастіше — доріжка не в моніторингу. У REAPER: увімкнути **Record-arm** (`R`) на доріжці. В інших DAW — «Input Monitoring». Перевірити, що MIDI справді доходить (індикатор активності на доріжці). |
| **Звук глухий / тихий** | `Gain` за замовчуванням `−12 дБ`; `Brightness` `35 %`. Підняти обидва. `Filter` має бути `Off` або cutoff високий. |
| **Клац при швидких пасажах понад 24 ноти** | Крадіжка активного голосу без fade-out — задокументована плата за компактний `Voice` (`07 §14`). |
| **Латентність / зсув фази при перемиканні HQ** | Латентність **константна** (16 семплів, повідомляється в `initialize`); при HQ off плагін сам додає компенсаційну затримку. Хост не повинен ре-запитувати PDC при тумблінні HQ. |
| **Неправильна висота тону** | Хост подав SR поза `[8000, 768000]` Гц — плагін клампить до межі й пише попередження в лог (не відхиляє activate). Реальні DAW завжди в діапазоні. |
| **Педаль сустейну не тримає ноти** | CC#64 обробляється лише в плагіні (не в C-ABI). Перевірити, що педаль шле саме CC#64 і DAW передає плагіну сирі MIDI CC (плагін заявляє `MidiConfig::MidiCCs`; деякі хости мають окремий тумблер «pass MIDI CC» на треку). |
| **Афтертач/MPE не змінює тембр** | `Expr → Bright` на `0 %` вимикає ефект — підняти. Контролер має слати poly aftertouch, MPE-тембр (CC74) або channel pressure; для MPE увімкнути MPE-режим у DAW. Впливає лише на осцилятор Geometric. |
| **Не знаю, чи треба вмикати HQ Mode** | Дивись метр аліасингу — кольорова смуга праворуч від спектра. Червона → вмикай HQ (смуга впаде). Зелена → HQ нічого не дасть, лишай вимкненим (він додає 16 семплів латентності). |
| **Метр аліасингу «горить», хоча Character вимкнений** | Дуже висока `Brightness` (`r → 1`) кладе реальні високі гармоніки в ту саму смугу — метр вимірює енергію біля Найквіста, не сам фолд. Якщо всі нелінійні (Drive/Fold/Grit/FM/Feedback) на нулі — це не аліасинг, HQ не потрібен. |

## 7. Жива DAW-валідація

Повний протокол ручного тестування (ініціалізація, буфери, зміна SR,
автоматизація, state recall, кілька інстансів, сустейн, voice-stealing,
GUI) — **`11_DAW_CHECKLIST.md`**, із журналом результатів по кожному хосту.

**Стан:** перший прогін у REAPER 7.79 (CLAP, Windows 11) пройдено — звук, GUI,
спектр, пресети, рандомайзер працюють; знайдено й виправлено накладання секцій
редактора. Решта груп чек-листа й інші хости — попереду.
