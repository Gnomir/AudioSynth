# 12 — Практичний гайд: збірка, встановлення, використання

`harmonic_synth` — поліфонічний MIDI-інструмент (**VST3 + CLAP**) на
`harmonic_core`. Кожна нота — band-limited адитивний тон із закритої форми
ядра Діріхле: без вейвтейблів, без циклу по гармоніках, без оверсемплінгу
(окрім опційного HQ-режиму).

---

## 1. Збірка з коду

Потрібен Rust `stable` (проєкт закріплено на `1.97`; nih-plug тягне важке
дерево — перша збірка кілька хвилин).

```
cd harmonic_synth

# швидка перевірка, що плагін компілюється
cargo build --release

# повні бандли VST3 + CLAP
cargo xtask bundle harmonic_synth --release
```

Результат:

```
target/bundled/harmonic_synth.vst3     (тека-бандл: Contents/x86_64-win/…)
target/bundled/harmonic_synth.clap     (один файл)
```

Опційно — прогнати валідатори (потрібні `pluginval` і `clap-validator` на
`PATH` або в `harmonic_synth/tools/`; pwsh-скрипт має `-Fetch` для
автозавантаження):

```
cargo xtask validate
```

## 2. Встановлення в DAW

### Варіант А — системні теки плагінів

Скопіювати в стандартні теки (потребує прав на запис — на Windows це
зазвичай адміністратор):

| ОС | VST3 | CLAP |
|---|---|---|
| Windows | `C:\Program Files\Common Files\VST3\` | `C:\Program Files\Common Files\CLAP\` |
| Linux | `~/.vst3/` | `~/.clap/` |
| macOS | `~/Library/Audio/Plug-Ins/VST3/` | `~/Library/Audio/Plug-Ins/CLAP/` |

VST3 копіюється як **тека** `harmonic_synth.vst3` цілком, CLAP — як файл.

### Варіант Б — додаткова тека сканування (без адмін-прав)

Більшість DAW дозволяють вказати власну теку для сканування плагінів —
можна навести її прямо на `target/bundled/` і нічого не копіювати.

**REAPER:**
1. `Options → Preferences` (`Ctrl+P`).
2. `Plug-ins → VST` → поле «VST plug-in path(s)» → **Add** →
   `…\harmonic_synth\target\bundled` → **Re-scan**.
3. `Plug-ins → CLAP` (окрема сторінка у сучасних версіях) → той самий шлях →
   Re-scan. У деяких версіях CLAP сканується з VST-шляхів автоматично.

Ключі в `reaper.ini` (секція `[reaper]`), якщо редагувати напряму при
закритому REAPER: `vstpath64=…` і `clap_path_win64=…` (шляхи через `;`).

## 3. Швидкий старт

1. Створити нову доріжку (`Track → Insert New Track`).
2. Відкрити FX доріжки → пошук **«Harmonic»** → додати `Harmonic Synth`
   (VST3 або CLAP — звучать ідентично).
3. **Увімкнути моніторинг доріжки**, інакше наживо звуку не буде:
   - **REAPER:** натиснути **Record-arm** (кнопка `R` на доріжці) — тоді
     віртуальна клавіатура (`View → Virtual MIDI Keyboard`) і зовнішня
     MIDI-клавіатура долітають до синтезатора.
   - Інші DAW: увімкнути «Input Monitoring» / «Monitor» на доріжці.
4. Грати нотами (MIDI-клавіатура, віртуальна клавіатура, або намалювати
   MIDI-айтем).

Плагін стартує в **чистому** стані: `Drive/Fold/Grit/FM/Feedback = 0`,
`Filter = Off`, `Brightness = 35 %`. Це майже синус із геометрично-спадними
гармоніками.

## 4. Параметри

| Параметр | Діапазон | Що робить |
|---|---|---|
| **Oscillator** | Geometric / Saw / Triangle | Geometric — закрита адитивна форма (реагує на Brightness + HQ). Saw/Triangle — PolyBLEP/PolyBLAMP (ігнорують Brightness і HQ). |
| **Brightness** | 0–100 % | Геометричний нахил спектра `r`. 0 % ≈ чистий синус, 100 % ≈ яскравий імпульс. |
| **Attack / Release** | 0.5 мс – 2 с · 5 мс – 5 с | Амплітудна обгинаюча (attack лінійний, release експоненційний). Sustain фіксовано на 1 (AR-обгинаюча). |
| **Gain** | −60 – 0 дБ | Майстер, перед soft-clip. |
| **Drive** | 0–100 % | Асиметричне насичення (bias їде разом). «Жир». |
| **Fold** | 0–100 % | Рефлективний вейвфолдер. Щільний рухливий верхній спектр. |
| **Grit** | 0–100 % | Bit-crush + пониження SR разом. Ранньоцифровий бруд. |
| **FM Amount / FM Ratio** | 0–4 · 0.5–12 | Фазова модуляція синусним оператором. Цілі Ratio — гармонічно, дробові — кланг. |
| **Feedback** | 0–0.9 | Самофідбек оператора. Синус → пила → шум. |
| **Filter** | Off / LP / BP / HP / Notch | ZDF SVF після Character-стадії. |
| **Cutoff / Resonance** | 20 Гц – 20 кГц · 0–100 % | Q `0.5 → 32`, без самозбудження. Cutoff автоматизується по-блоково. |
| **Filter Env** | −6 – +6 окт | Окрема фільтрова обгинаюча → cutoff, посемплово на голос. Біполярна. |
| **F.Env Attack/Decay/Sustain/Release** | | Власна ADSR фільтрової обгинаючої, незалежна від амплітудної. |
| **Free-Run Phase** | on / off | Аналоговий стиль: фаза осцилятора не скидається на note-on. |
| **HQ Mode** | on / off | `2×` оверсемпл усього тракту, щоб Drive/Fold/Grit/FM не аліасили. **+16 семплів латентності** (повідомляється хосту, PDC компенсує). CPU при цьому суттєво не зростає, але й не падає. |
| **Unison** | 1–8 | Стек розстроєних + стерео-рознесених голосів на ноту (гейн `1/√n`). |
| **Uni Detune / Uni Spread / Uni Drift** | 0–50 ц · 0–100 % · 0–100 % | Розстройка, стерео-ширина, і повільний незалежний дрейф фази на голос («дихання» образу). |
| **Bend Range** | 1–24 пт | Діапазон колеса висоти. |
| **LFO Rate / Shape / Sync** | 0.02–30 Гц · sine/tri/saw · Retrigger/FreeRun | По-голосний LFO. Retrigger — фаза скидається на note-on; FreeRun — біжить крізь ноти. |
| **LFO → Bright / Vibrato / Cutoff / FM** | ±100 % · 0–100 ц · ±4 окт · ±4 | Матриця модуляції LFO. Кожна ціль `0` не застосовується; усі нулі → LFO не рахується взагалі. |

Drive / Fold / Grit / FM / Feedback навмисно виводять контент за Найквіст і
аліасять на сильних значеннях (характер PPG / DX7). Для чистого результату —
**HQ Mode**. На нулі все одно чисто.

## 5. MIDI

| Подія | Обробка |
|---|---|
| Note On / Off | Виділення голосу, unison-стек. 24 голоси (unison ділить пул). |
| Choke | Миттєве глушіння (ігнорує сустейн). |
| Pitch Bend | На всі звучні голоси, згладжено. Діапазон — `Bend Range`. |
| CC#64 (sustain pedal) | Поки педаль тиснута (`value ≥ 0.5`), `NoteOff` відкладається; на відпусканні всі утримані ноти звільняються. |
| CC#123 (all notes off) | Звільняє всі голоси, скидає стан педалі. |

Канал MIDI-подій не розрізняється — плагін монотембральний (`07 §15`).

## 6. Траблшутинг

| Симптом | Причина / рішення |
|---|---|
| **Плагін не з'являється в списку FX** | Тека `target/bundled` не в шляхах сканування DAW, або сканування не перезапущене. Перевірити точний шлях (без нічого після `bundled`), натиснути Re-scan. |
| **Плагін завантажується, але немає звуку** | Найчастіше — доріжка не в моніторингу. У REAPER: увімкнути **Record-arm** (`R`) на доріжці. В інших DAW — «Input Monitoring». Перевірити, що MIDI справді доходить (індикатор активності на доріжці). |
| **Звук глухий / тихий** | `Gain` за замовчуванням `−12 дБ`; `Brightness` `35 %`. Підняти обидва. `Filter` має бути `Off` або cutoff високий. |
| **Клац при швидких пасажах понад 24 ноти** | Крадіжка активного голосу без fade-out — задокументована плата за компактний `Voice` (`07 §14`). |
| **Латентність / зсув фази при перемиканні HQ** | Латентність **константна** (16 семплів, повідомляється в `initialize`); при HQ off плагін сам додає компенсаційну затримку. Хост не повинен ре-запитувати PDC при тумблінні HQ. |
| **Неправильна висота тону** | Хост подав SR поза `[8000, 768000]` Гц — плагін клампить до межі й пише попередження в лог (не відхиляє activate). Реальні DAW завжди в діапазоні. |
| **Педаль сустейну не тримає ноти** | CC#64 обробляється лише в плагіні (не в C-ABI). Перевірити, що педаль шле саме CC#64 і DAW його передає плагіну. |
