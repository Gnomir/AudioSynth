## 1. Character — керована недосконалість (`character.rs`)

Чисте ядро — правильний *фундамент*, бо брудний сигнал не відмиєш, а чистий
забрудниш будь-коли. `Character` — увесь бруд, під ручкою, нічого від
похибок процесора. `CharParams::CLEAN` → `process` це **бітова identity**.

Порядок стадій у `Character::process(x: f32) -> f32`:

### 1.1. Асиметричне насичення

```
pre = (x + bias·0.3) · (1 + drive·8)
y   = tanh_pade(pre)                       // Паде: x(27+x²)/(27+9x²), clamp |x|≤4
```

`drive ∈ [0,1]`: до `×9` підсилення у сатуратор → «жир», гармоніки низького
порядку. `bias ∈ [−1,1]`: асиметрія → парні гармоніки + постійна складова
(знімається наступною стадією).

### 1.2. DC-blocker

Одно-полюсний high-pass, `R = 0.9995`:
`hp = y − x₁ + 0.9995·y₁`; `x₁ ← y`; `y₁ ← hp`; `y ← hp`.
Прибирає постійну складову від `bias`.

### 1.3. Рефлективний вейвфолдер (Buchla/Serge)

Точне трикутне відображення в `O(1)` (без ітеративних відбиттів):

```
fold ∈ [0,1]
g   = 1 + 4·fold                           // пре-підсилення в фолдер
thr = 1 − 0.97·fold                        // поріг: 1.0 (немає фолда) → 0.03
period = 4·thr
u   = frac( (y·g + thr) / period )
tri = if u < 0.5 { period·u − thr } else { 3·thr − period·u }
y   = tri / thr                            // makeup: назад до ±1
```

При `fold = 0` блок пропущено (гілка `if fold > 0`), тож identity збережено
охороною. Неперервність при `fold → 0⁺`: `g→1`, `thr→1`, `tri = y`.
Додає щільний, рухливий верхній спектр.

### 1.4. Bit-crush

```
crush ∈ [0,1]
bits   = 12 − 10·crush                     // 12-біт (ледь помітно) → 2-біт (знищено)
levels = 2^(bits − 1)                      // exp2
y      = round_f32(y · levels) / levels
```

### 1.5. Пониження частоти дискретизації (sample & hold)

```
downsample ∈ [0,1]
factor = 1 + 15·downsample                 // тримати кожні 1..16 семплів
hold_ctr += 1
if hold_ctr ≥ factor { hold ← y; hold_ctr −= factor }
y = hold
```

### Виміряний ефект

`examples/character_demo.rs`, відношення енергії верх/середина:
clean `0.01` → fold `0.10` → feedback `0.31` → FM `0.78`.

### 1.6. HQ mode — 2× оверсемплінг (`Character::process_hq`)

Стадії 1.1–1.5 генерують компоненти вище Найквіста і **навмисно аліасять**
при сильних налаштуваннях (характер PPG / DX7). Для чистого результату —
HQ mode (`Voice::set_hq(true)` / плагінний «HQ Mode»):

1. Осцилятор аналітичний → проміжний підсемпл рахується прямо:
   `geometric_partials(phase + 0.5·step, …)` — без FIR-інтерполяції входу.
   FM-модулятор теж береться в дробовій точці `fm_phase + 0.5·fm_step`.
2. Обидва підсемпли проходять `stage()` (шейпер→фолд→краш→S&H) на 2× частоті;
   період S&H множиться на 2, щоб зберегти wall-clock час утримання.
3. **Децимація** — 13-тапний лінійно-фазовий half-band FIR (віконний sinc,
   ненульові тапи `0, ±1, ±3, ±5`, стопбенд ≈ −50 дБ):
   `y = h₀·d₆ + h₁(d₅+d₇) + h₃(d₃+d₉) + h₅(d₁+d₁₁)`.

Латентність: **`HQ_LATENCY = 3` семпли** (group delay FIR). `hq = false` —
бітово ідентично попередній поведінці, нуль латентності. Не покрито:
`soft_clip` майстра, 4× режим, оверсемплінг фільтра.

## 2. FM + фідбек оператора (`voice.rs`)

Фазова модуляція несучої синусним модулятором + самофідбек:

```
pm = fm_index · sin_turns(fm_phase) + feedback · last_osc
osc = geometric_partials(phase + pm, r_eff, n) / peak
fm_phase += f_eff · fm_ratio / f_s   (wrap через floor_f64)
```

- `fm_ratio ∈ [0, 64]` — частота модулятора / основна. Цілі — гармонічно;
  дробові — дзвінко/кланг.
- `fm_index ∈ [0, 8]` — глибина (в обертах фази несучої). `0` вимикає
  (гілка пропускає `sin_turns`).
- `feedback ∈ [0, 0.9]` — самофазовий фідбек; синус → пила → шум.

## 3. State-variable фільтр — ZDF/TPT (`filter.rs`)

### 3.1. Виведення (Cytomic / Andrew Simper)

Неперервний SVF описується системою:

$$\dot v_1 = \omega_c(v_0 - k v_1 - v_2), \qquad \dot v_2 = \omega_c v_1,$$

де `v_1` — band-pass, `v_2` — low-pass, `k = 1/Q`, `ω_c = 2π f_c`.

Трапецієдальне (bilinear) інтегрування з прогином `g = tan(ω_c T/2) = tan(π f_c/f_s)`
дає нульову зворотну затримку (ZDF). Розв'язання неявної системи на семпл:

```
a1 = 1 / (1 + g·(g + k))
a2 = g·a1
a3 = g·a2

v3 = v0 − ic2
v1 = a1·ic1 + a2·v3
v2 = ic2 + a2·ic1 + a3·v3
ic1 ← 2·v1 − ic1        // оновлення стану інтеграторів
ic2 ← 2·v2 − ic2
```

Виходи:

| Режим | Формула |
|---|---|
| Low-pass | `v2` |
| Band-pass | `v1` |
| High-pass | `v0 − k·v1 − v2` |
| Notch | `v0 − k·v1` |
| Bypass | `v0` (бітова identity) |

### 3.2. Параметри

- `cutoff` клампиться в `[20 Hz, 0.45·f_s]` (щоб `g = tan(...)` лишався
  скінченним).
- `Q = 0.5 · 2^(6·res)` для `res ∈ [0, 1]` → `Q ∈ [0.5, 32]`. **Обмежено —
  не самозбуджується.**
- `k = 1/Q`.

### 3.3. Посемплове згладжування (Задача 1)

`cutoff` і `res` мають цілі (`cutoff_t`, `res_t`) та згладжені (`cutoff_z`,
`res_z`) значення. Усередині `process`:

```
якщо |cutoff_t − cutoff_z| > 1e-3 → cutoff_z += (1−smooth)·(…); recompute_g()
якщо |res_t    − res_z|    > 1e-6 → res_z    += (1−smooth)·(…); recompute_k()
якщо щось рухалось               → recompute_a()
```

`smooth` — одно-полюс ~1 мс. У сталому режимі всі три `recompute_*`
пропускаються (нуль вартості). Хост може кидати `cutoff` по-блоково без
зіпера; фільтрова ADSR може кидати посемплово.

### 3.4. Стійкість

ZDF-формулювання безумовно стійке: `a1 = 1/(1 + g(g+k))`, `g ≥ 0`,
`k ≥ 1/32` → знаменник `≥ 1`. Тест `stable_under_cutoff_and_resonance_sweep`
проганяє свіп cutoff при `res = 1` на 200 000 семплів без NaN / вибуху.

## 4. ADSR (`env.rs`)

Одна реалізація для амплітудної та фільтрової обгинаючих.

| Стадія | Оновлення на семпл | Перехід |
|---|---|---|
| Attack | `level += 1/(a·f_s)` (лінійно) | `level ≥ 1` → Decay |
| Decay | `level += coeff_d·(sustain − level)` | `|level − sustain| < 10⁻⁴` → Sustain |
| Sustain | `level = sustain` | `sustain < 10⁻⁴` → Idle (перкусійно, звільняє голос) |
| Release | `level += coeff_r·(0 − level)` | `level < 10⁻⁴` → Idle |

**Коефіцієнти з `exp2`**, щоб стадія `t` секунд *завершувалась* за ≈ `t`, а
не за `5t` (як наївний `1/(t·f_s)` одно-полюс):

```
coeff_d = 1 − 2^(−7.64 / (d·f_s))     // ~0.5 % від sustain лишається через d с
coeff_r = 1 − 2^(−13.3 / (r·f_s))     // ~ −80 дБ через r с
```

`trigger()` починає attack з *поточного* рівня (вкрадений голос
ретригериться без клацання). Дві незалежні інстанції на голос — тест
`filter_envelope_is_independent_of_amp_envelope` показує, що фільтровий свіп
(`sustain 0`) закриває HF `~11×`, поки амплітудна обгинаюча тримає ноту.

## 5. LFO (`lfo.rs`)

Фазовий акумулятор в обертах. Усі форми фазово-вирівняні (0 у фазі 0), щоб
зміна форми посеред ноти не давала стрибок.

| Форма | `tick()` |
|---|---|
| Sine | `sin_turns(p)` |
| Triangle | `p<0.25: 4p` · `p<0.75: 2−4p` · інакше `4p−4` |
| Saw | `p<0.5: 2p` · інакше `2p−2` |

`set_rate(hz, f_s)` → `inc = clamp(hz/f_s, 0, 0.499)`. Синус LFO рахується
через `sin_turns_fast` (16-біт — це модулятор, не несуча).

**Key-sync режим** (`LfoMode`, `set_lfo_mode`):

| Режим | На note-on (`retrigger()`) |
|---|---|
| `Retrigger` (дефолт) | фаза → 0 |
| `FreeRun` | фаза не чіпається — LFO біжить крізь ноти (аналог `free_running` осцилятора) |

**Матриця модуляції** (`set_lfo_targets(to_rolloff, to_pitch_cents, to_cutoff_oct, to_fm)`).
Кожна ціль `== 0` **не застосовується взагалі** — і якщо всі чотири нулі, LFO
навіть не тикається (clean fast path, `03 §2`).

| Ціль | Діапазон | Застосування в `render_sample` |
|---|---|---|
| `lfo_to_rolloff` | `[−0.9, 0.9]` | `roll_eff = clamp(rolloff_z + d·m, r_min, r_max)` |
| `lfo_to_pitch` | `[−1200, 1200]` центів | `f_eff ·= exp2(d·m / 1200)` |
| `lfo_to_cutoff` | `[−8, 8]` октав | `filter.set_cutoff(filter_cutoff · exp2(d·m))` — `filter_cutoff` це остання база від хоста; композиться з фільтровою обгинаючою мультиплікативно |
| `lfo_to_fm` | `[−8, 8]` | `fm_index_eff = max(fm_index + d·m, 0)` |

`m ∈ [−1, 1]` — вихід `tick()`. Плагін: `LFO Sync` (enum), `LFO → Cutoff`
(±4 окт), `LFO → FM` (±4).

## 6. Панорама рівної потужності (`voice.rs`)

`pan ∈ [−1, 1]`, згладжено `pan_z` (одно-полюс ~10 мс). Кут
`θ = (pan_z·0.5 + 0.5)·(π/2)`, в обертах `(pan_z·0.5 + 0.5)·0.25`:

```
(sin_p, cos_p) = sin_cos_turns_fast((pan_z·0.5 + 0.5)·0.25)   // 16-bit trig — це модулятор
[L, R] = [mono·cos_p, mono·sin_p]
```

- `pan = −1` → `θ = 0` → `[mono, 0]` (повністю ліворуч);
- `pan = +1` → `θ = π/2` → `[0, mono]` (повністю праворуч);
- `pan = 0` → `θ = π/4` → `[0.707·mono, 0.707·mono]` (−3 дБ, рівна потужність).

Тест `equal_power_pan_splits_correctly`: hard-left «протікання» < 5 %,
центр збалансований у межах 5 %.

## 7. De-click + free-running фаза (`voice.rs`, Задача 1)

`free_running: bool` керує поведінкою `reset()` (note-on):

- **`false`** → `phase = 0`, `fm_phase = 0`, `last_osc = 0`, `declick = 16`.
  Далі `render_sample` множить вихід на рампу
  `dg = (16 − declick)/16`, `declick` декрементується → лінійний fade-in за
  16 семплів (`~0.33 мс` @ 48k) маскує розрив фази.
- **`true`** → фази **не** чіпаються, продовжують рух (класичний аналоговий
  осцилятор); `declick` не вмикається.

Тест `free_running_phase_survives_note_on` + `declick_ramps_in_from_near_zero`.

## 8. Pitch bend (`voice.rs`, `poly.rs`)

Мультиплікативне відношення `bend = 2^(semitones/12)`, згладжене `bend_z`
(одно-полюс ~5 мс, щоб грубі MIDI-кроки колеса не зіперили).
`f_eff = freq_z · bend_z · 2^(вібрато)`. `PolySynth::set_pitch_bend` фанаутить
на всі звучні голоси. Плагін мапить `NoteEvent::MidiPitchBend { value }`
(0..1, центр 0.5) → `(value − 0.5)·2·bend_range` семитонів (діапазон —
параметр, деф. ±2).

## 9. Унісон (`poly.rs`)

`set_unison(count 1..8, detune_cents, spread 0..1, drift 0..1)`. На note-on
стекається `count` голосів; голос `i` з `n`:

| Параметр | Значення (`x = 2i/(n−1) − 1 ∈ [−1,1]`) |
|---|---|
| Детюн | `detune_cents · x` центів → `freq · 2^(cents/1200)` |
| Панорама | `spread · x` |
| Стартова фаза | `i/n` (декореляція) |
| Фаза LFO | `i/n` |
| Швидкість | `velocity · 1/√n` (таблиця, без `f32::sqrt`) |
| **Дрейф** (`drift > 0`, `n > 1`) | повільна вільна синусоїда `→ фаза осцилятора`: ставка `0.12·(0.55 + 0.9·i/n)` Гц (кожен голос трохи інакше → стек не ре-локається), глибина `drift · 0.05` обертів пікова, стартова фаза `i·φ` (золотий перетин) |

**Дрейф — це і є «дихання» образу.** Статичний детюн + панорама дають
правильну, але **нерухому** ширину; повільний незалежний дрейф фази на кожен
голос змушує сумарний гребінь повільно свіпувати → ширина стерео
модулюється в часі. `voice.rs`: `drift_phase/inc/depth`, `sin_turns_fast`,
не ретригериться (`reset()` не чіпає) — сенс саме в тому, щоб не збиватися
докупи. `+3 f64` на голос (Voice 552 → 576 б).

**Мікро-затримка на голос унісону — розглянуто, не додано.** Делей-буфер
0–20 мс на голос — це `~4 КБ`/голос (`~96 КБ` на `PolySynth<24>`), що ×7
розриває RAM-бюджет `08 §2.3` заради ефекту, який дрейф фази вже дає без
жодного буфера. Якщо колись знадобиться повніший ensemble — окремим кроком,
бажано за feature-gate.

`note_off` звільняє всі голоси з тим самим `note`. Тести:
`unison_stacks_voices_and_spreads_stereo` (ширина `0.61` для 7×);
`unison_drift_makes_the_image_breathe` (детюн 0 → базова ширина нерухома
span `0.00`; `drift 0.3/0.7/1.0` → span `0.06/0.15/0.22`, образ не колапсує).

## 10. Soft-clip (`poly.rs`)

Насичувач `ℝ → (−1, 1)`, Паде-апроксимація `tanh`:

```
soft_clip(x) = x·(27 + x²) / (27 + 9x²),   clamp |x| ≤ 3
```

Identity у першому порядку → тихі сигнали проходять чисто. `x = 1` → `0.78`;
`x = 3` → `1.0`. Застосовується покомпонентно (L, R) на виході
`PolySynth::render_sample` після майстер-гейну.

## 11. BLIT пилка / трикутник (`voice.rs::blit_saw`, `blit_triangle`)

Альтернативні форми осцилятора: `Waveform::Saw`, `Waveform::Triangle`
(`Waveform::Geometric` — типова, закрита форма §01). Вибираються
`Voice::set_waveform` / `PolySynth::set_waveform` / C-ABI
`harmonic_voice_set_waveform` / параметр плагіна **Oscillator**.

Повне виведення — `01_MATHEMATICS.md` §7. Коротко:

| | Пилка | Трикутник |
|---|---|---|
| Джерело | `BLITₙ(p)/T − 1/T` (нульове середнє) | біполярний BLIT: `(BLITₙ(p) − BLITₙ(p−½))/T` |
| Інтегратори | 1, витік `τ ≈ 0.5 с` | 2; стадія 2 витік `τ ≈ 20 мс` (кут ≈ 8 Гц) |
| DC-blocker | `R = 0.9995` | `R = 0.997` на кожній стадії |
| Спектр (вим.) | `1/k` (`h₂ 0.50`, `h₃ 0.33`) | непарні `1/k²` (`h₃ 1/9`, `h₅ 1/25`), парні `< 1.5 %` |
| Амплітуда | `≈ ±0.9` | `≈ ±0.45` |
| Стан на голос | `saw_int` + 2 DC | `saw_int`, `tri_int` + 4 DC (`saw_*` спільні — Saw і Triangle не грають разом) |

**Обмеження:** ігнорують `rolloff` та HQ; трикутник має м'який спад баса
(≈ −1.5 дБ на 55 Гц, ≈ −5 дБ на 28 Гц — ціна витоку стадії 2, який тримає
подвійний інтегратор від втечі на високих `f₀`); на `f₀ > 3.5` кГц `h₃`
трикутника завищений через `n ≤ 3`. Залишок над Найквістом `< 2 % h₁`.
Скидаються в `Voice::reset`.
