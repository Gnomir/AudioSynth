# 01 — Математичний фундамент

Осцилятор `harmonic_core` синтезує тон із перших `n` гармонік основної
частоти `f₀` за **однією закритою формулою**, без циклу по гармоніках, без
таблиці хвиль, без фільтра передискретизації. Фундамент — дві класичні
тотожності скінченного тригонометричного ряду.

Позначення: фаза `p` — в **обертах** (`1 оберт = 2π рад`), `x = 2πp`,
`c_k ≡ cos(kx) = cos(2πkp)`.

---

## 1. Ядро Діріхле (плаский спектр)

### 1.1. Твердження

$$D_n(x) \;\equiv\; \sum_{k=1}^{n}\cos(kx)
   \;=\; \frac{\sin\!\big((n+\tfrac12)x\big)}{2\sin(x/2)} \;-\; \frac12 .$$

В обертах:

$$D_n(p) = \frac{\sin\!\big(\pi(2n+1)p\big)}{2\sin(\pi p)} - \frac12 .$$

### 1.2. Виведення

Розглянемо повну геометричну суму комплексних експонент:

$$\sum_{k=0}^{n} e^{ikx} = \frac{e^{i(n+1)x}-1}{e^{ix}-1}
  = \frac{e^{i(n+1)x/2}}{e^{ix/2}}\cdot
    \frac{e^{i(n+1)x/2}-e^{-i(n+1)x/2}}{e^{ix/2}-e^{-ix/2}}
  = e^{inx/2}\,\frac{\sin\!\big((n+1)x/2\big)}{\sin(x/2)} .$$

Дійсна частина (тотожність Лагранжа):

$$\sum_{k=0}^{n}\cos(kx)
  = \frac12 + \frac{\sin\!\big((n+\tfrac12)x\big)}{2\sin(x/2)} .$$

Віднявши член `k=0` (що дорівнює 1), отримуємо `D_n(x)`. $\square$

### 1.3. Властивості

| Властивість | Значення | Наслідок для DSP |
|---|---|---|
| Пік при `p→0` | $\displaystyle\lim_{p\to0}D_n(p)=n$ (за правилом Лопіталя) | Це **band-limited impulse train (BLIT)** — сплеск щоперіоду |
| Середнє за період | $0$ | Немає постійної складової на виході |
| Спектр | Рівно `n` гармонік однакової амплітуди, нуль вище `nf₀` | **Немає аліасингу**, поки `nf₀ < f_s/2` |
| Усувна особливість | `sin(πp)=0` при `p ≡ 0 (mod 1)` | Код повертає `n` при `|sin(πp)| < 10⁻⁹` (`kernel.rs::dirichlet_blit`) |

### 1.4. Числова перевірка (`n=2`, `p=0.25`)

Пряма сума: `cos(π/2) + cos(π) = 0 + (−1) = −1`.
Закрита форма: `sin(1.25π)/(2·sin(π/4)) − 0.5 = (−√2/2)/(√2) − 0.5 = −0.5 − 0.5 = −1`. ✓

## 2. Геометрична сума (спектральний нахил)

### 2.1. Твердження

Для `0 < r < 1`:

$$S_n(x,r) \;\equiv\; \sum_{k=1}^{n} r^k\cos(kx)
  \;=\; \frac{r\,c_1 - r^2 - r^{\,n+1}c_{n+1} + r^{\,n+2}c_n}
             {1 - 2r\,c_1 + r^2}.$$

### 2.2. Виведення

Нехай `z = r e^{ix}`, `|z| = r < 1`. Скінченна геометрична сума:

$$\sum_{k=1}^{n} z^k = \frac{z\,(1 - z^n)}{1 - z}.$$

Домножимо чисельник і знаменник на спряжене `\overline{(1-z)} = 1 - \bar z`:

$$\sum_{k=1}^{n} z^k
  = \frac{z\,(1 - z^n)\,(1 - \bar z)}{|1 - z|^2}.$$

Знаменник:

$$|1 - z|^2 = (1 - r\cos x)^2 + (r\sin x)^2 = 1 - 2r\cos x + r^2.$$

Чисельник:

$$z(1 - z^n)(1 - \bar z)
  = (z - z^{\,n+1})(1 - \bar z)
  = z - z\bar z - z^{\,n+1} + z^{\,n+1}\bar z
  = z - r^2 - z^{\,n+1} + r^2 z^{\,n}.$$

(використано `z\bar z = |z|^2 = r^2` і `z^{n+1}\bar z = z^n\,|z|^2 = r^2 z^n`).

Взявши дійсну частину (`Re\,z^k = r^k\cos(kx)`):

$$S_n = \frac{r\cos x - r^2 - r^{\,n+1}\cos((n+1)x) + r^{\,n+2}\cos(nx)}
             {1 - 2r\cos x + r^2}. \qquad\square$$

Це рядок `kernel.rs:88–90`:
```rust
let num = r*c1 - r*r - rn1*cn1 + rn2*cn;   // rn1 = r^{n+1}, rn2 = r^{n+2}
let den = 1.0 - 2.0*r*c1 + r*r;
num / den
```

### 2.3. Властивості

**Немає сингулярної фази.** Знаменник
`1 − 2r cos x + r² = (1 − r cos x)² + (r sin x)² ≥ (1 − r)² > 0`
для всіх `x` при `r < 1`. На відміну від `D_n`, який ділить на `sin(πp)` і
потребує охоронної гілки, `S_n` числово стійкий при **будь-якій** фазі. Тому
`geometric_partials` — основний шлях; `dirichlet_blit` викликається лише при
`r ≥ 1`.

**Границя `r → 1⁻`.** `S_n → D_n` (знаменник → `2(1 − cos x) = 4sin²(x/2)`).
Код: `if r >= 1.0 { return dirichlet_blit(p, n) }`.

**Границя `r → 0⁺`.** `S_n → r cos x`, після нормування на пік (див. 2.4) →
чиста синусоїда основної частоти. Тому ручка «brightness» `r` йде від
чистого тону до яскравого імпульсу.

**Спектральний нахил.** Гармоніка `k` має амплітуду `rᵏ`, тобто
`20·log₁₀(r)` **дБ на гармоніку** (сталий крок у дБ *на гармоніку*, не на
октаву — це конкретна форма нахилу, не універсальний EQ). Для `r = 0.9`:
`≈ −0.92 дБ/гарм`; `r = 0.99`: `≈ −0.087 дБ/гарм`.

### 2.4. Нормування (пік)

Пік `S_n` — при `p → 0`, де всі `c_k → 1`:

$$S_n(0, r) = \sum_{k=1}^{n} r^k = \frac{r\,(1 - r^n)}{1 - r}.$$

`geometric_peak(r, n)` повертає цю величину; `Voice` ділить сирий вихід на
неї, щоб сигнал лежав приблизно в `[−1, 1]`. Для `r ≥ 1` пік = `n`
(значення `D_n(0)`).

## 3. Точна скінченність — основа заяви про смугу

Члени `r^{n+1}c_{n+1}` та `r^{n+2}c_n` — це **точна корекція**, яка робить
`S_n` *скінченною* сумою, а не нескінченним рядом
`Σ_{k=1}^{∞} rᵏ cos(kx) = (r c₁ − r²)/(1 − 2r c₁ + r²)`.

Ці члени зникають у нуль лише коли `r^{n+1} < 2⁻¹⁰⁷⁴` (мінімум денормалів
f64), тобто:

$$n + 1 > \frac{1074}{\log_2(1/r)}.$$

Для `r = 0.999`: `n > 744 000`. Для `r = 0.99`: `n > 74 000`. Тобто для
**будь-якої реальної кількості аудіо-гармонік** (`n ≤ 2048`) закрита форма
є точною скінченною band-limited сумою, біт-у-біт (у межах похибки
тригонометрії, §4). Це і є підстава твердження «не аліасить, поки
`n ≤ ⌊f_s/(2f₀)⌋`» — вище цього клампу гармонік просто немає в сумі.

`Voice::render_sample` обчислює `n = ⌊f_s/(2·f_eff)⌋`, обмежене
`MAX_PARTIALS = 2048`, де `f_eff` враховує pitch bend і вібрато.

## 4. Поширення похибки

Кожен `c_k = cos(2πkp)` рахується діапазонно-редукованим поліномом Горнера
(`02_NUMERICAL_METHODS.md`) з абсолютною похибкою `ε ≈ 2·10⁻¹¹`.

**Аргумент.** `2πkp` для `k ≤ n ≈ 2048`, `p ∈ [0,1)` сягає `~1.3·10⁴` рад,
тобто `kp ≤ 2048` обертів. Редукція через `round(kp)` точна у f64
(`kp < 2⁵²`), тому редукований аргумент не втрачає значущих цифр.

**Сума.** У чисельнику `S_n` домінантні за похибкою — члени `c_1` (масштаб
`r`) та `c_{n+1}, c_n` (масштаб `r^{n+1}`, малий при `r` близькому до 1).
Знаменник обмежений знизу `(1 − r)²`. Структурна оцінка:

$$|\hat S_n - S_n| \;\lesssim\; \varepsilon\cdot\frac{r + r^{\,n+1} + r^{\,n+2}}{(1-r)^2}
  \;\approx\; \frac{\varepsilon\,r}{(1-r)^2} \quad (r \to 1).$$

При `r = 0.9995`: `≈ 2·10⁻¹¹ · 0.9995 / (2.5·10⁻⁷) ≈ 8·10⁻⁵` абс. Але
`|S_n| ~ n ≈ 2000` у цьому режимі, тож **відносна** похибка `~4·10⁻⁸`.

**Вимірювання** (тести `kernel::geometric_matches_naive_sum`,
`dirichlet_matches_naive_sum` проти прямої суми): збіг у межах
`10⁻⁹·n` (скаляр) і `5·10⁻⁶·n + 10⁻⁶` (батч x4) для `n` до 1500–2048.

## 5. Обчислювальна складність

На один вихідний семпл:

| Операція | Вартість |
|---|---|
| `c_1`, `c_n`, `c_{n+1}` (3× `cos_turns`) | фіксована, `Θ(1)` |
| Арифметика формули `S_n` | `Θ(1)` |
| `powi_pos(r, n+1)` — піднесення до степеня квадруванням | `⌊log₂(n+1)⌋ + popcount(n+1) ≤ 2⌈log₂(n+1)⌉` множень |
| `powi_pos(r, n)` у `geometric_peak` | те саме |

Для `n ≤ 2048`: `≤ 22` множень у циклі. Отже:

> **Θ(log n)** на семпл у найгіршому; **Θ(1)** за фіксованих `r`, `n`.

`Voice` кешує `powi_pos(r, n+1)` та пік за ключем `(r, n)`
(`voice::geom_norm`, kernel-и `geometric_partials_pre` / `geometric_peak_pre`
приймають готове значення). На сталій ноті обидва `powi_pos` не рахуються, і
вартість **виміряно** плоска по `n` (розкид `< 1 %` на `n ∈ [3, 1200]` проти
`~400×` для наївного `Θ(n)` банку). Але це кеш, не алгоритмічне `O(1)`: на
зміні `r` (свіп brightness) чи `n` (зміна висоти) `powi_pos` перераховується.
Чесне формулювання — амортизовано `Θ(1)` за майже сталих параметрів,
`Θ(log n)` у найгіршому. Див. `07_LIMITATIONS.md §1`.

## 6. Що з цієї математики НЕ випливає

- **Пилкоподібна хвиля.** `Σ sin(kx)/k` не має елементарної закритої форми
  (пов'язана з функцією Клаузена). Band-limited пилка/трикутник тут робляться
  інакше — **PolyBLEP / PolyBLAMP** (§7 нижче, `04_DSP_COMPONENTS.md`): наївна
  хвиля + поліноміальна корекція в точках розриву. Не закрита форма й не
  Фур'є-ряд — часова область, без стану.
- **Довільний спектр.** Закрита форма існує лише для плаского (`D_n`) та
  геометричного (`S_n`) розподілів — це наслідок сумовності скінченного
  геометричного ряду. Довільна обгинаюча на кожну гармоніку — знову `Θ(n)`.
- **Відсутність аліасингу після нелінійних стадій.** `character`, FM,
  feedback, `soft_clip` — усі генерують компоненти вище Найквіста. §3
  стосується *чистого* осцилятора. Див. `07_LIMITATIONS.md`.

## 7. Band-limited пилка та трикутник (PolyBLEP / PolyBLAMP)

Окремий шлях від закритої форми §1–§4: `Waveform::Saw` / `Waveform::Triangle`.
Реалізація — `voice.rs::polyblep_saw` / `polyblamp_triangle`, **без стану**.
Метод — Välimäki & Huovilainen (2007). Позначимо `dt = f_eff / f_s` (приріст
фази на семпл), `p ∈ [0,1)`.

### 7.1. Ідея

Наївна хвиля має розрив: пилка — стрибок значення на межі періоду; трикутник —
злам нахилу у двох кутах. Наївне семплування такого розриву дає нескінченний
спектр → аліасинг. **PolyBLEP** віднімає різницю між band-limited і
розривним сходинковим кроком, апроксимовану поліномом на вікні `±dt` навколо
розриву. **PolyBLAMP** — те саме для зламу нахилу (це `∫ PolyBLEP`).

### 7.2. Пилка

$$y(p) \;=\; (2p - 1) \;-\; \mathrm{blep}(p),\qquad
  \mathrm{blep}(t)=\begin{cases}
   2x - x^2 - 1, & x=\tfrac{t}{dt},\ t<dt\\[2pt]
   x^2 + 2x + 1, & x=\tfrac{t-1}{dt},\ t>1-dt\\[2pt]
   0 & \text{інакше}
  \end{cases}$$

Спектр `1/k`, амплітуда `±1` (виміряно `f₀ ∈ [27.5, 6000]` Гц:
`h₂/h₁ = 0.50`, `h₃/h₁ = 0.33`; фундаментал `±0.02` дБ від ідеалу аж до
27.5 Гц).

### 7.3. Трикутник

Наївний трикутник `1 - 4|p - \tfrac12|` (пік `+1` у фазі 0, `−1` у ½, нахил
`±4` на оберт). Два кути; у кожному нахил стрибає на `±8·dt` на семпл:

$$y(p) \;=\; \big(1 - 4|p-\tfrac12|\big)
   \;+\; 4\,dt\cdot\mathrm{blamp}(p)
   \;-\; 4\,dt\cdot\mathrm{blamp}\!\big(\{p+\tfrac12\}\big)$$

$$\mathrm{blamp}(t)=\begin{cases}
   -\tfrac13 x^3, & x=\tfrac{t}{dt}-1,\ t<dt\\[2pt]
   \phantom{-}\tfrac13 x^3, & x=\tfrac{t-1}{dt}+1,\ t>1-dt\\[2pt]
   0 & \text{інакше}
  \end{cases}$$

Спектр: лише непарні, `h₃/h₁ = 0.110` (ідеал `1/9`), `h₅/h₁ = 0.040` (`1/25`),
парні `< 0.1 %`. Амплітуда `±1`, фундаментал `±0.00` дБ від ідеалу до 27.5 Гц.

### 7.4. Вартість і чесність

- **Без стану, без рекурсії, без тригонометрії.** ~6 флопів (пила) / ~15
  (трикутник) на семпл — виміряно **90 / 77 M семплів/с** проти ~26 M у
  геометричного осцилятора (тобто **дешевше за несучу**).
- Ігнорує `rolloff` (спектр фіксований `1/k` / `1/k²`) та HQ.
- **Не** точно band-limited: BLEP/BLAMP — поліноміальна апроксимація
  ідеального ядра, а не зрізаний ряд Фур'є. Alias-floor `< −90` дБ до `f₀ ≈
  1` кГц; на `f₀ > ~3` кГ фундаментал і верхні гармоніки трохи спадають
  (`−0.11` дБ на 3 кГц, `−0.45` дБ на 6 кГц). У музичному діапазоні —
  нечутно; на A7 пилкою ніхто не грає.
- Плаский відгук до DC — жодного HPF (це і був сенс переходу з leaky-BLIT,
  який давав `−5` дБ на 28 Гц).
